Tucuxi Benchmarking Dev-User Documentation
==========================================

This documentation contains a description of two python scripts used to validate Tucuxi:

    - tucuvalidation.py, responsible to cross-check tucucli with NONMEM, description available here :ref:`here <crosscomparison>`.

    - models_comparison.py, responsible to compare different Tucuxi models, description available here :ref:`here <modelscomparison>`.

The documentation is not meant for the end user, but for people working on new
drug models.
