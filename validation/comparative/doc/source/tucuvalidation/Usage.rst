=====
Usage
=====

Tests can be launched with a command as simple as this one: ::

    ~$ ./tucuvalidation.py -t <path_to_tuculi> -n <path_no_nonmem>

This would start the tests for every query found in the query path 'data/queries'.

To start a test on a single query file, run: ::

    ~$ ./tucuvalidation.py -t <path_to_tuculi> -n <path_no_nonmem> -queryfile <queryfile>

To generate graphs, add ``--graph``, and to generate a Junit report, add ``--junit``.

*To get the help:* ::

	~$ ./tucuvalidation.py -h

*Tests description:*

The tests are based on query files. These query files correspond to the format tucuserver would deal with. A query contains some administrative data that are not used for these tests. The interesting data is split into the drug treatment (dosage, samples, covariates, targets), and requests. A request is a single calculation, and so there can be many requests in a single query. For each request NONMEM is started with the corresponding data.

The final point density for curves in Tucuxi is used as the time points in NONMEM data files.

Percentiles graphs are generated by running the NONMEM files in the model folder, and by running Tucuxi with the same data from simulating 10000 patients.
